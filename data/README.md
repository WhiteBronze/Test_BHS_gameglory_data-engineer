# Данные для тестового задания (синтетические)

Две «выгрузки» о вымышленных играх, как будто полученные из двух разных систем. Все данные
**синтетические**: игры, студии и отзывы сгенерированы, совпадения с реальными продуктами случайны.
Данные специально «грязные» — это часть задания.

```
data/
├── fx_rates.csv              курсы валют к USD (одни на обе порции)
├── batch_1/                  первая выгрузка (2026-09-01)
│   ├── store_export.json     источник 1 «Магазин»: карточки игр (~500)
│   ├── stats.csv             источник 2 «Статистика»: аудитория и рейтинг тех же игр
│   └── reviews.jsonl         отзывы игроков (~3000), один JSON-объект на строку
└── batch_2/                  вторая выгрузка (2026-09-15) — те же три файла:
                              новые игры, изменения цен, повторы уже загруженного
```

## store_export.json

```json
{ "source": "store", "batch": "batch_1", "exported_at": "2026-09-01T06:00:00Z",
  "items": [ {
    "store_id": "ST-100950",
    "title": "Foundry of Vesstead",
    "developer": "Static Lamb Labs", "publisher": "Tallowmere Media",
    "release_date": "2021-02-15",
    "price": { "amount_cents": 2499, "currency": "USD" },
    "tags": "RTS;STRATEGY;BASE-BUILDING; Multiplayer  ;fantasy;Resource-Management; Singleplayer  ",
    "genres": ["Strategy"], "platforms": ["windows", "mac"] } ] }
```

- `store_id` — идентификатор игры в магазине (ключ источника 1).
- `price.amount_cents` — цена в **минимальных единицах** валюты (центы, евроценты, копейки), `currency` ∈ USD / EUR / RUB.
- `exported_at` — момент выгрузки; используйте его как дату наблюдения цены.

## stats.csv

| Поле | Описание |
|---|---|
| `ext_id` | идентификатор игры во втором источнике (с `store_id` **не связан**) |
| `name`, `year` | название и год релиза — по ним игру нужно сопоставить с магазином |
| `owners` | оценка числа владельцев |
| `ccu_peak` | пик одновременных игроков |
| `positive_pct` | доля положительных отзывов, % |
| `reviews_total` | число отзывов по данным источника |
| `updated_at` | когда источник обновил строку |

Числа записаны по-разному: `452148`, `"1,234"` и `1 234` (разделитель тысяч), в `positive_pct` бывает десятичная запятая (`"95,6"`); пустое поле — значение неизвестно.

## reviews.jsonl

```json
{"review_id": 1459, "game_ref": "ST-978900", "voted_up": true, "text": "...", "playtime_hours": 27.5, "created_at": "2021-08-04T13:07:07Z"}
```

`game_ref` ссылается на `store_id` из `store_export.json`.

## fx_rates.csv

`currency,usd_per_unit,as_of` — сколько USD стоит одна единица валюты (например, 1 EUR = 1.08 USD).
Для простоты используйте один курс для обеих выгрузок.
